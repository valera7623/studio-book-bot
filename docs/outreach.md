# Аутрич и онбординг (GTM)

Канал продавать не нужно: студии уже принимают брони в Telegram вручную. Продавать **ссылку и шаблон за вечер**.

База: карточки studiorent.ru, Photoplace, studiogo (часто есть «написать в Telegram»). Чаты фотографов/студий — демо в нативной среде. Агрегаторы — партнёры: отдать занятость через iCal, не конкурировать виджетом.

## Короткое сообщение владельцу

```
Здравствуйте! Вижу, запись у вас идёт в Telegram / переписке.

Собрали бота только под почасовую аренду зала: клиент по одной ссылке выбирает слот, вносит предоплату, слот сам сгорает если не оплатили, напоминание за 24 ч и за 2 ч.

Не CRM и не виджет на сайт. Онбординг — название, зал, часы, цена; ссылка и QR сразу.

Тарифы 490 / 990 ₽ в месяц, эквайринг как обычно у кассы. Демо: https://t.me/Studio_book_bot
Коротко на сайте: https://studiobook.com.ru
```

## Что владелец отправляет клиентам

Тексты после /studio → «Тексты для клиентов» (подставляется живая ссылка).

Клиентам:

```
Теперь записаться в {студия} можно через бот:
{ссылка}
Выберите зал и время, внесите предоплату — слот закрепится сам. Напомним за сутки и за 2 часа.
```

В сторис / канал:

```
Свободные окна и запись без переписки: {ссылка}
```

## Учёт воронки (вне репозитория)

Студия → ответила → создала студию в боте → первая оплата слота клиентом → подписка 490/990.

Колонки таблицы — в [pain_check.md](pain_check.md). Сюда ФИО/телефоны не писать.

## Когда начинать рассылку

Не раньше: касса в проде ([go_live.md](go_live.md)), одна студия оплатила слот, есть ответы 8–10 владельцев по скрипту боли. Рекламу на лендинг не крутить до этого.

## Каталоги (30 / 60 / 90 дней)

Искать карточки фотостудий с «написать в Telegram» / «бронь в директ»:

- https://studiorent.ru
- Photoplace
- studiogo

В день: 8–12 коротких сообщений из блока выше, не спам пачками. В таблицу: дата, каталог, код студии, ответ, студия в боте, оплата слота, подписка.

Агрегаторам, если спросят про занятость: `https://studiobook.com.ru/ical/<slug>.ics` — не виджет на их сайт.

## Kill 3–5%

Считать: `подписки 490/990 / число студий, которым написали`.

- 30 дней: если 0 оплат слота при ответах — сначала цена/триал, не фичи.
- 90 дней: конверсия студия → платный **ниже 3–5%** → гипотеза 490/990 не подтверждена; менять оффер, не кабинет «как у YCLIENTS».
- Bookform или DIKIDI выпускают полный клиентский сценарий в Telegram с предоплатой → не ценовая война.

Не строить: CRM, второй канал VK/WhatsApp, комиссию с оборота.
